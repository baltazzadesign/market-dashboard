발타툴 GOLD UI V6 · 초기 제안 시안 레이아웃

목표
- 사용자가 선택한 최초 제안 시안(검정/금색 동양풍)의 전체 화면 구성을 실제 발타툴 대시보드에 최대한 가깝게 적용
- 단순 색상 변경이 아니라 데스크톱 레이아웃 자체를 시안과 같은 방향으로 재구성
- 기존 KIS/Supabase/API/cron/차트 계산 로직은 수정하지 않음

변경 핵심
1. 데스크톱 좌측 고정 사이드바 제거 -> 상단 가로 네비게이션으로 전환
2. 깔끔한 발타툴 로고 + 대시보드/시장 수급/시장폭/Market Pulse/섹터 분석/종목 스캐너/캘린더 메뉴
3. 리서치 검색형 상단 버튼 + 발타경/발타 중용 접근 유지
4. 대형 동양풍 Hero: '시장을 읽는 발바닥의 감각' + 금빛 달/산수화 분위기
5. 지수 카드 4개를 시안과 같은 금테 프레임 카드로 정리
6. 메인 차트 + Market Pulse/투자자 수급 우측 레일 구조 강화
7. 시안 하단과 같은 시장 캘린더/섹터 분석/종목 스캐너/차트 전체보기 4개 카드 추가
8. 발타의 서재(발타경/발타 중용) 유지
9. 책임면책 고지를 최초 제안 시안처럼 큰 하단 고지 박스로 강화
10. 모바일은 기존 대응을 유지하며, 이번 작업은 PC 시안 일치도를 우선함

덮어쓸 파일
- app/globals.css
- components/dashboard/Workspace.tsx
- components/dashboard/InvestmentDisclaimer.tsx

적용 후
npm run typecheck
npm run build
npm run dev

참고
- V6는 기존 V5가 적용된 프로젝트 기준 패치입니다.
- 새로운 npm 패키지는 필요하지 않습니다.
- 서버/API/KIS/Supabase/cron 관련 코드는 포함하지 않습니다.
