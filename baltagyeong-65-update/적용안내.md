# 발타경 1차~65차 사이트 업데이트

현재 사이트는 XLSX를 직접 읽지 않고 `public/baltagyeong.html`을 엽니다. 그래서 엑셀 내용을 사이트용 HTML로 변환해 둔 묶음입니다.

## 적용
1. `baltagyeong-65-update` 폴더를 발타툴 프로젝트의 `package.json` 옆에 둡니다.
2. VS Code 터미널에서 실행: `node baltagyeong-65-update/install.mjs`
3. `http://localhost:3000/baltagyeong.html` 확인
4. 정상이라면 `git status` → `git add public/baltagyeong.html components/dashboard/Workspace.tsx` → `git commit -m "Update Baltagyeong to 65 parts"` → `git push`

이미 우측 상단 발타경 버튼이 있으면 버튼은 중복 추가하지 않고 `public/baltagyeong.html`만 새 내용으로 교체합니다.

구성: 65차 / 1082장 / 4370절. 검색창도 포함했습니다.
