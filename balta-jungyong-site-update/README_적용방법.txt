발타 중용 · 중용 문체 정제본
===========================

기존 /balta-jungyong 페이지를 업데이트하는 파일입니다.

적용 방법
---------
1. 기존 프로젝트의 app/balta-jungyong 폴더를 다른 위치에 백업합니다.
2. 이 압축 안의 app 폴더를 프로젝트의 app 폴더와 합치고 같은 파일을 덮어씁니다.
3. fonts 폴더까지 함께 복사해야 합니다. 파일 4개만 따로 복사하지 마세요.
4. 이미 있는 발타 중용 상단 버튼은 다시 추가할 필요가 없습니다.
5. 프로젝트 터미널에서 npm run build 로 확인합니다.
6. 평소 Git push로 자동 배포하고 있다면 다음 명령을 실행합니다.

   git add app/balta-jungyong
   git commit -m "refine jungyong text and manuscript reader"
   git push

※ Git push 후 사이트 반영 여부는 기존 자동 배포 설정과 배포 성공 여부에 따릅니다.

최종 폴더 구조
--------------
app/balta-jungyong/
  page.tsx
  BaltaJungyongReader.tsx
  balta-jungyong.module.css
  data.ts
  fonts/
    regular.woff
    bold.woff
    OFL.txt

변경 사항
---------
- 기존 33장의 제목과 주제를 유지하여 전체 본문을 새로 정제했습니다.
- 반복되는 훈계와 불필요한 연결 문장을 덜고, 대구와 점층의 문체로 통일했습니다.
- 제23장은 작은 원칙에서 습관과 행동의 변화로 이어지는 중심 장입니다.
- 실제 발언의 직접 인용처럼 보이는 표현을 없앴습니다.
- 이 글은 중용의 문체를 빌린 창작 패러디이며, 중용의 각 장을 번역하거나 일대일로 대응한 글이 아닙니다.
- 한지색 바탕, 먹색 본문, 절 번호, 붉은 인장, 얇은 고서 테두리로 구성했습니다.
- 짧은 문장마다 생기던 강조 상자와 큰 첫 글자 장식을 없앴습니다.
- Noto Serif KR 명조체를 로컬 글꼴로 포함했습니다. 방문자가 외부 폰트 서버에 접속할 필요가 없습니다.
- 본문 크기는 PC 기본 20px / 모바일 기본 18px이며, 가− / 가＋로 조절합니다.
- 기존 저울 아이콘, 목차, 본문 검색, 이전/다음 장, 장 주소 기능을 유지했습니다.
- 검색 결과 없음 안내와 모바일 목차 접근성을 개선했습니다.

본문을 고치려면
---------------
app/balta-jungyong/data.ts의 title과 blocks를 수정합니다.
발타중용_정제본문.txt는 읽기와 내용 검토용입니다. txt만 수정하면 사이트에는 반영되지 않습니다.
기본 한글 완성형 음절 전체가 글꼴에 포함되어 있습니다. 추가 한자는 기기 기본 명조체로 표시될 수 있습니다.
