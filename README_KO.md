폴더 구조를 유지해 위 5개 파일을 프로젝트에 복사하세요. 기존 파일 2개는 먼저 백업하세요. 작업 이후 프로젝트가 바뀌었다면 market-pulse.patch를 검토해 변경 부분만 병합하세요. manifest.json에는 작성 당시 원본과 수정본의 SHA-256이 있습니다.

적용 후 프로젝트에서 실행:

```text

```

## 화면과 호환성

시장 브리핑과 Command Center에 0~100점, 시장 국면, 데이터 충족도, 5가지 판정 근거를 표시합니다. 기존 marketScore, 차트, CSV, 저장 신호, 알림, DB 스키마, 수집 API는 변경하지 않습니다. 과거 달력의 Pulse는 기존 점수이므로 새 종합 점수와 다를 수 있습니다. 국면은 조회 시 계산하며 저장하지 않습니다.

## 점수 규칙

| 입력 | 비중 | 기준 |
|---|---:|---|
| 시장폭 | 30% | (상승−하락)/전체 종목 수, ±60%에서 포화 |
| 외국인·기관 | 25% | 각각 누적 순매수 ±3,000억원에서 포화 후 평균 |
| KOSPI·KOSDAQ | 20% | 10~15분 전 대비 등락률, 각각 ±0.5%에서 포화 후 평균 |
| 섹터 강도 | 15% | 기존 섹터 강도 산식 사용, 양 시장별 평균을 동등 반영 |
| 가속·변곡 | 10% | 시장폭 비율 변화와 직전 가속도, 최근 5분 저장 변곡 신호 |

각 입력을 −1~1로 제한합니다. 사용 가능한 입력의 가중평균을 0~100으로 변환하며 결측을 중립 0으로 간주하지 않습니다. 충족도는 사용 가능한 입력의 비중 합계입니다. 점수와 충족도는 예측 확률이 아닙니다.

가속 항목은 10~15분 전 시장폭 비율 변화(±15%p에서 포화)를 사용합니다. 직전 3분 안의 정상 시장폭 기록이 있으면 저장 accel(±150개에서 포화)을 추가합니다. 두 정보가 모두 있으면 장중 변화 50%, 직전 가속 20%, 변곡 30%; 직전 가속이 없으면 장중 변화 70%, 변곡 30%입니다. 과거 정상 시장폭 비교가 없으면 이 항목 전체를 제외합니다.

## 국면 우선순위

시장폭·정상 수급·양 지수 비교가 있고 충족도 65% 이상일 때 판정합니다. 그 외에는 판정 대기와 참고 점수를 표시합니다.

1. 투매: 시장폭 비율 ≤−50%, 수급 입력 ≤−0.25, 양 지수 각각 ≤−0.15%, 가속·변곡 입력 ≤0.
2. 반전 시도: 이전 시장폭 <−15%, 현재 <20%, 가속·변곡 ≥0.35, 최근 상방 변곡만 존재, 지수 입력 >0, 수급 입력 ≥−0.2.
3. 위험: 점수 ≤35 또는 시장폭 <−20%와 지수 약세 또는 하방 변곡·가속 악화·지수 약세.
4. 강세: 점수 ≥72, 시장폭 ≥30%, 수급 입력 >0, 양 지수 각각 ≥0.05%, 하방 변곡 없음.
5. 상승 지속: 점수 ≥58, 이전·현재 시장폭 >10%, 수급 ≥0, 양 지수 각각 ≥0.05%, 가속·변곡 ≥−0.1, 하방 변곡 없음.
6. 혼조: 위 조건에 해당하지 않음.

기준값은 v1의 명시적 휴리스틱이며 실증 성과 검증을 거친 최적값은 아닙니다.

## 데이터 경계

- 해당 날짜 정규장(09:00~15:30)만 계산합니다. 장후에는 마지막 정규장 시각을 표시합니다.
- 시장폭과 수급은 LIVE만 반영합니다. 양 지수는 양수인 유효 기록과 비교 구간이 필요합니다.
- 섹터는 기존 저장 조회 API를 이용합니다. 양 시장 각각 유효한 섹터 3개 이상, 같은 날짜, 기준 행보다 미래가 아니며 15분 이내인 정규장 시각만 허용합니다.
- 장후에 섹터 저장값이 덮어써졌거나 과거 시간대 자료가 없으면 섹터를 제외합니다. 현재 API는 시계열 섹터 이력을 제공하지 않습니다.
- 최근 상방·하방 변곡이 동시에 있으면 반전 시도로 판정하지 않습니다.
- 기존 DB 데이터를 수정하거나 누락 자료를 소급 생성하지 않습니다.

## 화면 확인

대시보드와 Command Center에서 카드와 5가지 판정 근거 펼치기를 확인하세요. 날짜 변경 시 다른 날짜의 섹터가 섞이지 않고, 장후에는 정규장 기준 시각이 표시되는지 확인하세요. 실제 계정에 연결한 장중 화면 검증은 수행하지 않았습니다.
