발타툴 GOLD UI V2 패치
======================

전제
- 이전 GOLD UI 1차 패치가 적용된 현재 프로젝트 기준입니다.
- KIS / Supabase / cron / API / 시장 계산 로직은 수정하지 않습니다.

포함 파일
- app/globals.css
- components/dashboard/Workspace.tsx

2차 변경 내용
1. 좌측 상단 발타툴 로고를 단일·깔끔한 워드마크 형태로 강화
2. 대시보드 Hero가 발바닥 타짜 원본의 달/산수화 분위기를 더 잘 보여주도록 조정
3. 일반 카드의 금색 테두리를 줄이고, 핵심 영역만 금색을 강조해 화면 위계 개선
4. 우측 Market Pulse 영역의 존재감 강화
5. 메인 하단에 '발타의 서재' 추가
   - 발타경
   - 발타 중용 (33장)
6. 책임면책고지를 법적 Footer 성격으로 더 차분하게 정리
7. 모바일 전용 UI 개선
   - 상단: 발타툴 로고 + 상태 + 전체 메뉴 버튼
   - 하단: 대시보드 / 일별 / 캘린더 / 리서치 / 더보기 5개 메뉴
   - 더보기 메뉴: 시장 복기, 발타경, 발타 중용, 지표 가이드, 화면 설정, 책임면책고지
8. 모바일 카드/서재/면책고지 반응형 개선

적용 방법
1. 이 ZIP을 압축 해제합니다.
2. 압축 안의 app, components 폴더를 현재 market-dashboard 프로젝트 최상위 폴더에 덮어씁니다.
3. VS Code 터미널에서 아래 순서로 확인합니다.

npm run typecheck
npm run build
npm run dev

4. 브라우저에서 http://localhost:3000 확인

문제 발생 시
- 기존 프로젝트 파일을 삭제하지 말고, 이 패치에 포함된 2개 파일만 원복하면 됩니다.
- .env.local, KIS 키, Supabase 키는 수정 대상이 아닙니다.
