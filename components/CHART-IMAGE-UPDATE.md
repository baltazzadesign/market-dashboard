# 차트 PNG 저장 업데이트

## 적용

1. components(2).zip 압축 내용물을 프로젝트의 기존 components 폴더에 합쳐 덮어쓰기합니다.
2. 프로젝트 터미널에서 `npm run build`를 실행합니다.
3. 성공하면 `git add components`, `git commit -m "Add chart PNG export with detailed investor flows"`, `git push`를 순서대로 실행합니다.

## 전체 시장 차트 저장

- 대시보드, 일별 분석, 시장 수급, 차트 전체보기의 **전체 차트 PNG 저장** 버튼을 누릅니다.
- 투자자 수급 / 시장 폭 / 상승·하락 비율 / KOSPI / KOSDAQ / 시장폭 점수 / 시장 지수 비교 / 가속도 총 8개 차트와 투자자 세부 수급을 한 PNG에 저장합니다.
- 세부 수급은 KOSPI + KOSDAQ 합산 기준 금융투자·투신·사모·은행·보험·기타금융·연기금·기타법인 8개 항목을 모두 포함합니다. 화면의 세부 수급 시장 선택/숨김과 별개로 종합 이미지 기준을 명시합니다.
- 기본 차트/세부 수급 중 어느 탭에서 저장해도 두 내용을 모두 포함합니다.
- 일별 분석 및 전체보기에서는 선택한 날짜와 시간 범위를 반영합니다. 메인 대시보드는 수집 구간을 사용합니다.
- 지수 비교는 최초 공통 기록 대비 변화율이며 기준 시각을 표기합니다. 전체보기의 신호 켜짐/꺼짐을 반영합니다.
- 수치 요약은 표시 시간 범위 내 마지막 기록 기준입니다. 마지막 전체 수집 시각도 헤더에 별도 표시합니다.
- 모바일에서도 기본 차트는 고정 2열, 세부 수급은 전체 너비로 저장합니다. 캔버스 픽셀 수를 제한해 메모리 사용량을 줄입니다.
- 누락·오류 값은 —로 유지합니다. 세부 수급 기록이 없는 날도 제목과 미제공 안내를 이미지에 포함합니다.

## 종목 수급 분석 저장

- **차트 이미지 저장** 버튼으로 주가·거래량·선택한 투자자 수급과 기간 합계를 저장합니다.
- 선택한 기간, 투자자, 금액/수량, 누적/일별, 겹쳐보기/분리보기, 주가 표시를 반영합니다.
- 종목명·코드·주가 기준일·수급 기준일·조회 시각과 누락 안내를 포함합니다.

## 동작 및 검증

- 클릭 시 현재 데이터와 옵션을 고정하고, 기존 차트 SVG를 브라우저에서 PNG로 변환합니다.
- 저장 도중 중복 클릭 방지, 오류 안내, 재시도 및 화면 이동 시 작업 취소를 처리합니다.
- 이미지 저장에 추가 API 호출이나 서버 업로드가 필요하지 않습니다. 패키지, 환경 변수, SQL 변경이 없습니다.
- TypeScript/Next.js 프로덕션 빌드와 Chromium의 실제 PNG 다운로드를 확인했습니다.
- 9개 차트 포함, 8개 세부 수급 선, 30분 선택 구간, 모바일 레이아웃, 과거 데이터 누락, 빈 데이터, 실패 후 재시도, 종목 옵션 반영을 확인했습니다.
- QA 데이터는 검증용 파일에만 있으며 배포 코드에 포함되지 않습니다.
