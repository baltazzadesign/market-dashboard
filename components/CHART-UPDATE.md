# 발타툴 차트 개선 — 2026-09-29

> 이 문서는 앞선 차트 개선 내역입니다. 최신 적용 방법은 함께 들어 있는 SCORE-UPDATE.md를 우선 따르세요. 이번 점수 개선본은 components(2).zip과 lib(2).zip을 모두 적용해야 합니다.

## 적용 방법
1. 실행 중인 로컬 개발 서버를 종료합니다.
2. 이 ZIP을 압축 해제한 뒤 `dashboard` 폴더를 기존 프로젝트의 `components` 폴더 안에 덮어씁니다. (`components/dashboard/MarketCharts.tsx` 위치)
3. 새 파일 `components/dashboard/MarketCharts.module.css`가 함께 복사되었는지 확인합니다.
4. 프로젝트 터미널에서 `npm run build`를 실행합니다.
5. `npm run dev`로 홈/일별 분석의 차트 전체보기를 확인한 뒤 평소처럼 Git에 커밋하고 푸시합니다.

## 개선 내용
- 기본 시간 범위를 수집 구간에 맞추고 우측 여백을 1~5분만 확보합니다. 30분 / 1시간 / 전체 장 보기와 드래그 확대는 계속 선택할 수 있습니다.
- 전체보기에서 중복된 상태 문구를 위로 모으고 선·단위·축 눈금을 정리했습니다. 3열일 때 지수 비교는 마지막 행의 2칸을 사용합니다.
- 연결된 차트의 상단 수치가 커서 시각으로 함께 바뀌고, 벗어나면 최신값으로 돌아옵니다. 전체보기에서는 중복 팝업을 표시하지 않습니다.
- 전체보기 신호 점은 기본 꺼짐이며 상단 버튼으로 켤 수 있습니다. 겹치는 점을 줄였으며 수급 신호 점은 실제 표시 중인 수급 선 위에 위치합니다. 신호 기록과 계산은 바뀌지 않습니다.
- 지수 비교는 두 지수의 첫 공통 유효 기록을 0%로 맞추는 변화율 보기를 기본으로 사용합니다. 전일 종가 대비 수익률이 아닙니다. '지수' 버튼으로 기존 원지수/좌우축 보기로 전환합니다.
- 시장점수 ±100 경계에 여유를 두어 선이 잘리지 않게 했습니다.
- 빈 구간·모든 지표 숨김 상태에 안내를 표시합니다. 데이터 결측 구간을 보간하지 않고, 직전값/오류 출처를 구분합니다.
- 홈과 일별 분석 전체보기에 동일한 조작을 적용하고 모바일 1열·태블릿 배치를 확인했습니다.

## 검증
- 제공된 소스로 TypeScript 및 Next.js 프로덕션 빌드 통과.
- 시간 범위 경계, 공통 비교 기준, 결측/오류 값, 확대/이동 계산 회귀 검사 4개 통과.
- Chromium에서 홈·일별 전체보기, 커서/상단 수치 연동, 드래그 확대, 범위 선택, 신호 토글, 지표 숨김, 변화율/원지수, 확대 후 복귀, 빈 데이터/API 실패 화면 확인.
- 360 / 390 / 768 / 1366 / 1660px에서 차트 가로 넘침과 카드 내부 잘림 확인.
- 브라우저 검증에는 별도의 생성된 테스트 데이터를 사용했습니다. 테스트 데이터·임시 설정·환경변수는 ZIP에 포함되지 않습니다.
- 검증 환경: Next.js 16.2.4, React 19.2.4, Recharts 3.10.1 (제공된 ^3.8.1 범위).
- 프로젝트 루트 설정/잠금 파일은 첨부되지 않아 임시 설정으로 검사했습니다. 실제 프로젝트에서도 npm run build를 실행해 확인하세요.
